AI-powered home services booking through SMS. Like having one contact for all your home services.

== Description ==

Makase is an AI-enabled concierge that simplifies home services booking and management through familiar text messaging. This plugin integrates Makase's platform directly into your WordPress site.

**Key Features:**

* AI handles 95% of communication while keeping humans in the loop
* SMS-based booking - no apps needed
* Complete service management from booking to payment
* Perfect for plumbing, cleaning, HVAC, handyman, landscaping, and more

**How It Works:**

1. Add your Makase API ID to the plugin settings
2. Booking widget appears on your website
3. Customers interact via SMS
4. Makase's AI manages scheduling and coordination
5. You focus on service delivery

Currently serving San Diego with 2025 expansion to Orange County, LA, and Austin.

== Installation ==

1. Install and activate the plugin
2. Go to Settings → Makase Quote
3. Enter your Makase API ID
4. Save settings - widget now appears on your site
